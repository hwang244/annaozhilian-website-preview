# 安脑智联官网 · 公开预览发布包

这个目录仅包含 GitHub Pages 运行所需的静态文件：根目录版本选择页、`dark/` 深色版、`white/` 白色新版。原始 Word 策划、研究摘录、构建脚本、QA 文档、PNG 原图和联系表单预览测试内容均未放入发布包。

两版各有 6 个中文页面与 6 个英文页面。入口：`index.html`、`dark/index.html`、`white/index.html`。链接和素材路径均为相对路径，可放在 GitHub Pages 项目站点的子路径中。

网站为设计预览。资讯是待发布内容草案；预约表单只在浏览器中生成摘要，不会发送或保存信息。AI 生成的人物场景明确标为示意。

GitHub Pages 可在仓库的 Settings → Pages 中选择 Deploy from a branch、`main`、`/(root)`，网站会提供 `https://<用户名>.github.io/<仓库名>/` 地址。
