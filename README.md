# 安脑智联官网 · 公开预览发布包

这个目录仅包含 GitHub Pages 运行所需的静态文件：根目录版本选择页、`dark/` 深色版、`white/` 白色新版。原始 Word 策划、研究摘录、构建脚本、QA 文档、PNG 原图和联系表单预览测试内容均未放入发布包。

两版各有 6 个中文页面与 6 个英文页面。入口：`index.html`、`dark/index.html`、`white/index.html`。链接和素材路径均为相对路径，可放在 GitHub Pages 项目站点的子路径中。

网站为设计预览。资讯是待发布内容草案；预约表单只在浏览器中生成摘要，不会发送或保存信息。AI 生成的人物场景明确标为示意。

深色版已加入按场景挑选的图片、03 技术三联图、04 健康商城规划展示和 05 横向动态栏。公众号名称为「上海安脑智联」，文章链接与二维码尚待核实。英文页面使用公司全称 **AnnoBrain Intelligence Technology (Shanghai) Co., Ltd.**；`annobrain.com` 目前仅为推荐域名。

深色版的六个顶部栏目现在采用同一深蓝、青色与较厚字重的品牌体系，同时分别使用独立的首屏构图：产品突出居家康复与三端入口，技术突出 AI 系统与临床场景，动态采用编辑式横幅，关于我们使用团队画面，联系我们突出服务场景与表单。图片按各栏目内容从田总提供的素材中选用，并针对桌面和手机分别裁切。

两版均保留用户提供的 `logo-original.jpg` 作为品牌参考。原图中的英文多一个 L，网页展示区使用按原图图形重新排版的正确字样 **REHABILITATION**，导航及 favicon 使用简化标志。中文页面页脚同时列出上述英文公司全称。

GitHub Pages 可在仓库的 Settings → Pages 中选择 Deploy from a branch、`main`、`/(root)`，网站会提供 `https://<用户名>.github.io/<仓库名>/` 地址。
